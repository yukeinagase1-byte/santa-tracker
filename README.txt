SANTA TRACKER — MISSION CONTROL (PWA package)

WHAT THIS IS
- A mobile-friendly installable website/PWA package.
- Includes original synthesized festive chime music with Play/Pause/Stop controls.
- Map position, mission status, and letters counter are SIMULATED, not real Santa GPS.
- Official seasonal tracker link is inside the app.
- Offline caching is enabled after first visit, except external official links.

TO MAKE IT LIVE
1. Upload every file in this folder to a static web host that provides HTTPS.
2. Keep index.html, manifest.json, sw.js, and both icon PNG files together in the same folder.
3. Open the hosted HTTPS address on Android Chrome.
4. Use Chrome's menu and choose "Install app" or "Add to Home screen" (wording varies).

This bundle is not published to Google Play and is not an APK. Publishing to Google Play is a separate process.
